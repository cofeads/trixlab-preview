# TRIXLAB Shopify Theme

This original Shopify Online Store 2.0 theme includes:

- TRIXLAB vector brand system
- dark premium powersports homepage
- responsive product and collection templates
- live wrap configurator with color zones, presets, material, coverage, overlays, custom text and logo upload
- product variant matching for real Shopify checkout prices
- undo, redo, zoom, random design mixes and saved local builds
- cart display for all configuration properties
- English and German storefront translations

## Product setup

Create a Shopify product for every starting design. Use up to three product options such as:

1. Material: Standard Vinyl, Chrome, Holographic
2. Coverage: Partial, Full
3. Model: Spark 2UP 2022, Spark 3UP 2022

Every valid combination should be a Shopify variant with its real price and availability. The configurator maps controls to variants by option value and submits the selected variant ID. Colors, logo, text, overlay and production notes are submitted as line item properties.

## Install

Upload `TRIXLAB-Shopify-Theme.zip` in Shopify under Online Store → Themes → Add theme → Upload zip file.

After upload:

1. Assign a main and footer menu in the theme editor.
2. Select a featured collection on the homepage.
3. Link the hero and design studio buttons to your wrap collection or first product.
4. Add products with Material and Coverage variants.
5. Set social URLs and brand colors in Theme settings.
